## Debrief

- **What worked:** It functions simply and as intended, justifying each issue with the related ID from the upload. 
- **What broke / felt like a toy:** The upload of an actual file ended up breaking my prototype as it just wasn't robust enough to handle reading the data uploaded. This is the core job of this application, so it failed at a basic level - so any true evaluation had to happen with the "load sample" data, that was made up to be completely happy path friendly.
- **What I'd change next pass:** Error handling for uploading the data, so it doesn't crash the application.
